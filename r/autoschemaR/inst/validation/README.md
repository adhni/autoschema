# Shared validation fixtures and attribution

These files are the canonical offline inputs used by both AutoSchema Python and
native R tests. `manifest.json` records checksums, expected logical shape, blanks,
duplicates, options and required/rejected relationships. Tests never download data.

## Public data

- **penguins.csv** is an unchanged snapshot from the
  [palmerpenguins v0.1.0 release](https://github.com/allisonhorst/palmerpenguins/tree/v0.1.0).
  [Original CSV](https://raw.githubusercontent.com/allisonhorst/palmerpenguins/v0.1.0/inst/extdata/penguins.csv).
  Data collected by Kristen Gorman and the Palmer Station Long Term Ecological
  Research program. Horst AM, Hill AP, Gorman KB (2020), *palmerpenguins*,
  [doi:10.5281/zenodo.3960218](https://doi.org/10.5281/zenodo.3960218).
  Data license: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/),
  as stated in the [upstream license information](https://github.com/allisonhorst/palmerpenguins#license).
- **bike_daily.csv** contains the unchanged bytes of `day.csv` from the
  [UCI Bike Sharing archive](https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip).
  Fanaee-T, H. (2013), *Bike Sharing [Dataset]*, UCI Machine Learning Repository,
  [doi:10.24432/C5W894](https://doi.org/10.24432/C5W894).
  Data license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/),
  as stated on the [UCI dataset page](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset).
  The filename was changed from `day.csv`; the data were not changed.

The public snapshots were retrieved on 2026-11-22. Public data licenses apply to
these files independently of AutoSchema's MIT code license.

**penguins_blanks.csv** is a clearly marked derivative: exact `NA` tokens in the
public penguin data are replaced with empty fields, and CSV quoting/line endings
are regenerated. The original snapshot retains literal `NA` text. This tests both
behaviors without silently assuming that every `NA` token means missing data.

## Synthetic cases

The other CSVs are deterministic fixtures generated by
`scripts/generate_shared_fixtures.py` in the repository and use its MIT license.
They cover composite keys, conflicting mappings, wide tables with bounded search,
long identifiers, Unicode, BOMs, semicolon delimiters, quote/newline fidelity,
leading zeros, formatted/oversized numbers, duplicate empty rows and invalid data.
`invalid_domain_key` deliberately reuses the valid orders CSV with an invalid key.

To regenerate synthetic and derived fixtures, run from the repository root:

```sh
python scripts/generate_shared_fixtures.py
```

The generator retains the public snapshot bytes and checks their pinned SHA-256
hashes before regenerating derived data. Updating public data is a deliberate
source/provenance change, not an automatic download during tests.
